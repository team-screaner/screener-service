Screener — Swagger UI

Откройте метод → Try it out → заполните запрос → Execute.

Сначала вызовите POST /api/v1/auth/register или /auth/login. Пароль: 12–72 байта. Скопируйте поле token из ответа в Authorize без префикса Bearer. Токен хранится только до перезагрузки страницы.

Для операций с обязательным Idempotency-Key укажите новый уникальный ключ. Повтор того же запроса с тем же ключом вернёт сохранённый результат. Скачать OpenAPI JSON.
